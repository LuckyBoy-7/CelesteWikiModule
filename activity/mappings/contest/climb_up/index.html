    Climb Up Contest

    各位蔚蓝玩家好啊, 这里是 bits 像素, 画游 & 画布主办.

    画布竞赛的作品大家有没有游玩体验过呢? 各位有没有也想参加类似制图竞赛的意愿呢? 有没有也想为国内合集制作贡献力量的玩家呢?

    因此, 我计划再次举办合集制作, 举办 Climb Up Contest!

    Climb Up Contest 是面向蔚蓝 Celeste 所有中文社区玩家的又一次制图竞赛, 目的在于激励更多玩家尝试制图领域, 同时挖掘出中文社区制图水平的潜力. 我们欢迎一切中文社区玩家参与到本次制图竞赛中来!

    如果对于制图有兴趣, 想在本次制图竞赛中大展身手的 mapper, 可以加入比赛群聊 1080449788, 后续会在该群中公布 Climb Up Contest 的具体安排!

    如果之前没有对制图有所了解, 现在想进行尝试的玩家, 可以加入制图交流群 633125440, 蔚蓝制图需要新的血液加入!

    本次竞赛将对提交的地图从全方位进行考核, 最终入围正式进入合集的地图作者也将会获得一些奖励~

    以下是规则文档的摘抄, 由 bits 像素撰写

    一、竞赛规则与流程安排

    Climb Up Contest 是面向蔚蓝 Celeste 所有中文社区玩家的一次制图竞赛, 目的在于激励更多玩家尝试制图领域, 同时挖掘出中文社区制图水平的潜力. 我们欢迎一切中文社区玩家参与到本次制图竞赛中来!

    本次制图竞赛流程如下：

    • 2026.10.1------2027.6.30 mapper 制图环节
    • 2027.7.1 ------2027.7.31 评审团审图环节
    • 2027.8.1 ------2027.8.7 公布入选地图名单

    以上为暂定计划, 具体实施会根据参加情况有所调整. 如果出现大规模的 ddl 前无法完整相关环节等情况, 可以视情况延期一段时间.

    下面介绍具体各个环节的要求.

    二、竞赛主题

    竞赛主题：Climb Up（向上攀登）

    主题 "Climb Up" 是本场竞赛的核心命题, 其诠释不限于物理层面的垂直位移, 而应贯穿于地图的设计逻辑与体验内核之中.

    参赛作品可从以下维度切入主题：

    1. 机制与路径维度

    关卡的核心推进逻辑应体现 "上升" 的意志. 这既可以是宏观层面的整体海拔抬升, 也可以是微观操作中反复对抗重力、寻求高位落点的过程. 鼓励 mapper 围绕垂直空间设计独特的移动解法与路径规划.

    2. 氛围与叙事维度

    场景设计宜呈现明确的垂直层次感, 例如从低处向高处递进的景观变化. 剧情或情绪线索亦可与 "攀登" 对应, 展现从低谷走向高点、从混沌趋向清晰的变化曲线.

    3. 概念与表达维度

    允许对 "向上" 进行解构式诠释. 若地图整体趋势并非上升, 但核心机制、场景意象或叙事落脚点能够对 "攀登" 形成有力呼应, 亦属切题. 我们鼓励克制而深刻的表达, 而非流于形式的贴图或台词.

    评审原则：主题契合度将作为重要评审维度之一, 但不作为作品的准入门槛. 我们期待看到对 "攀登" 一词严肃、独特且自洽的设计回应.

    三、地图制作要求

    1. 地图要求

    您所提交的地图应当 由您本人或您本人代表的团体独立制作, 且 不应在其他地方发布过. 若为多名作者合作制图, 需给出所有作者名单.

    • 难度要求：下限酱二绿, 上限酱五红
    • 长度要求：gp 房间建议不少于 8 面, 单面长度不宜过长
    • 游玩要求：不限于正常单路线图, 可以制作解谜图, 特殊玩法图, 剧情图（需含有正常 gp）等, 但最终评审权归评审团所有. 我们欢迎一切有创意的玩法, 只要你能把它做好.
    • 美术要求：不影响正常游玩即可. 我们 重点看 gp, 但 gp 合格的前提下, 美术做好是可以加分的.
    • 音乐要求：不推荐使用官图 bgm. 尤其不要用默认的 awake）
    • 其他要求：地图禁止含有任何色情暴力等违法内容, 不得含有政治隐喻和歧视内容

    我们所提供的要求是 指导性要求, 在具体评审过程中会 结合地图实际情况考虑, 违反上述规定的情况我们会在 游玩体验方面酌情扣分（不包括第一项作者要求）

    2. 提交要求

    地图提交截止日期：2027 年 6 月 30 日

    提交途径：在 Climb Up Contest 竞赛群中发送 zip 文件, 文件名为作者_地图名.zip, 例如：

    1
    bits 像素_bubble pool.zip

    zip 内格式要求：参照竞赛群文件内地图模板

    截止日期内接受修改后重交, 但需删除之前提交的文件

    3. 保密要求

    地图除测试, 装修, code 外不应向他人传播, 直至评选结束后, 由评委公布入选名单, 入选地图后续继续保密, 落选地图由 mapper 自行决定是否公开. 同样, 你不应当泄露其他参赛人员的地图.

    4. 版权要求

    地图中所有非官图素材（音乐, 美术, code 等）, 非本人绘制的则需根据 credits 要求情况, 在地图内给出 credits 名单.

    对违反以上规则的地图和 mapper, 我们保留取消参赛资格的权利.

    四、地图审核标准

    我们不可能接收所有提交的地图, 但只要质量达标, 评分合格, 我们会尽可能接收更多的地图.

    具体评分标准如下：

    大项 小项 分值占比
    gameplay 游玩体验 40%
    难度平衡 5%
    镜头优化 5%
    创意程度 10%
    decoration 美术 15%
    音乐与剧情 5%
    Theme 主题契合度 20%

    每位评委将根据该评分标准对所有地图进行评分, 对评委评分标准化处理后得到平均值, 即为地图得分. 原则上评委不可参赛. 对于打分异常的评委, host 保留取消其评分资格的权利.

    除整体打分外, 还有其他突出奖项, 如最佳创意奖、最佳散步图奖、最佳剧情奖, 等等. 所有奖项在最终合集发布时会同步公开.

    五、入选与优化

    地图审核完成后, 我们会在竞赛群内公布入围地图名单, 并标记出前三名. 各位参赛 mapper 有为期一周的确认入围时间, 入围的地图将进入优化和合集制作的环节, 未入围的地图将交给其作者自行处理.

    优化环节包括但不限于 gp 和美术方面的优化, 同时在进入该环节后, 各位参赛选手可以互相帮助, 提供 decoration 和 gp 优化服务.

    如果优化环节 mapper 由于种种原因无法参加, 可以将地图转交给 host, host 将会安排人手对该图进行优化. 当然, 最终仍然会标记初始 mapper 为作者.

    关于心门制作：综合考虑了前几次合集举办的经历, 本次竞赛 最终没有心门制作环节.

    六、发布合集

    合集正式发布后, 会有奖励发放给各位得到奖项的 mapper. 原则上所有入围地图均可获得奖励.
