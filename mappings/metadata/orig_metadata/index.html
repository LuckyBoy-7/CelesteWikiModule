    官图元数据

    整合/摘抄

    • 官图元数据 by Everest Wiki

    由于官图的元数据是硬编码的, 所以你会发现如果直接把官图地图粘出来改不少地方都跟原来的效果对不上, 所以你可以将下面这些数据填入 .meta.yaml 里来达到和官图一样的效果 (虽然官图里还是有一大堆其他硬编码的东西啦)

    这里需要注意一件事, .meta.yaml 也是 A/B/C 面共享的, 所以如果你需要单独配置, 请在 Loenn 里勾选 Override A-Side Meta, 或是通过 Modes 分别为 A/B/C 面配置, 其他部分共用, 例如

    HeartIsEnd: false
  - Inventory: TheSummit # B side
    HeartIsEnd: true
  - Inventory: Farewell # C side
    HeartIsEnd: true
