    蔚蓝语速成

    原版

    术语 别名 / 英文 说明
    帮助模式 assist mode 免费的挂
    异变 variants 更好的挂
    cheatmode 可以提前解锁金草莓和暂停界面的草莓收集显示
    检查游戏完整性 恢复出厂设置 (Steam 功能)

    Mod

    术语 别名 / 英文 说明
    Everest eve Celeste 的开源 mod 加载器和 modding API
    Olympus oly 简洁的 mod 安装与管理工具, 支持 Windows / MacOS / Linux
    CeleMod 类似 Olympus, 但是国产
    ChinaMirror 中国镜像, WEG 的钱包 更快地下载和更新 mod
    单图 Standalone 单独发布的 mod 图
    合集 Collab 多作者合作的 mod 地图集
    群服 Miaonet, 喵服 联机 mod
    拓展异变 extended variants mod, 比更好的挂还好
    debug debug mode 调试模式 (可以在 Everest 的 mod 选项中启用)
    F6 debug map, 调试地图 传送挂 (前提是已开启调试模式)
    log.txt 不要再发 errorlog 了
    自动更新 你应该在 Mod 设置中关掉它

    常用

    术语 别名 / 英文 说明
    对准 setup 用特定方式将操作容错和时机固定
    冲刺 dash, 突进 塞莱斯特的迷之力量
    无冲 dashless 不用冲刺
    最少冲 minimum dash, min-dash 尽量不用冲刺
    TAS Tool Assisted Speedrun 让电脑帮你跑蔚蓝
    倒走 etselec 从终点往回走
    随机 mod randomizer 包含所有人类通关过的官图变种 (无冲, 单冲, 双冲)
    gp gameplay, 玩法 游戏的核心内容和玩法等, 而非画面或音效
    deco decoration, 装饰 地图的美术部分
    Clear C, 通关 有些视频的标题上会写一个神秘的 [C], 其实就是通关的意思
    FC Full Clear, 完全通关, 全通关 通关并且收集所有草莓、磁带、心。不是音游的那个 FC
    session 局 (游戏)
    正路 设计路线, intended route 作者认为他的图应该怎么过
    偷鸡 鸡, cheese 部分或者完全忽略正路的路线
    策略 strategy, strat, 路线 更优的走法, 通常会减少操作难度或减少用时
    202 收集官图包括金草莓的所有草莓 (175 红 1 月 1 飞金 25 金)
    cp1, cp2, cp3, ... checkpoint, 检查点 小节 (第一节, 第二节, ...)
    f1, f2, f3, ... flag, 旗子 1 旗, 2 旗, 3 旗, ... (对应合集心门中的每一小段)
    一面 一间, room 一个房间
    倒一 final 最后一个房间
    大肠面 大长面
    传奇单面 非常难的房间
    SL Speedrun Tool, srt, 速通工具, 大江之力 内含存读档、房间计时和快速切换房间的功能
    越级 越 打远超自己能力的图
    底力 地力 虽然有许多不同的解读方法, 但是核心还是指向一个人的实力
    手癖 癖 长时间推图后出现无法改正的错误手法, 导致无法进步的情况
    目押 盯 不依靠节奏, 通过目测时间点的方式进行操作
    音押 完全依靠节奏进行操作
    尾杀 结尾, ending 差一口气通关结果死了
    难图榜 hard list, hist, 榜 记录最难通关的榜单

    术语 别名 / 英文 说明
    any% 任意完成度 从创建存档到 7a 通关结束

    arb all red berries, 全红草莓 从创建存档到收集所有红草莓

    pb personal best 个人最佳

    术语 别名 / 英文 说明

    FC 金 fcg 无伤通关地图并且收集所有草莓、磁带、心
    金限 golden room 限定带金草莓才会出现的房间
    1a 双金 无冲金草莓和一命金草莓一起拿
    9dp 9d 铂 无伤 9d (+ 铂限)
    酒精 九金 无伤官图第九章 (+ 金限)
    金榜 golden list, molden 记录 mod 无伤的榜单
    gl good luck, 必 直播间知名黑话
    fluke 侥幸 第一次通过一大段高难部分且没有翻车
    choke 翻 快要赢了的时候失败了

    地图

    类型

    术语 别名 / 英文 说明
    抛接图 抛接 以抓取物 (如 Theo, 电池等)为主要玩法的地图
    对准图 将操作容错和时机固定的地图
    微操图 precision, 扭腰图 操作容错和时机相对严格的地图
    散步图 stroll, 散步, 休闲 p 轻松愉快的简单图
    剧情图 有一定量故事和演出的图
    自动图 不按按键或是按指定按键就能随意通关的图

    难度

    由于草莓酱作为蔚蓝 Mod 中不得不尝的合集, 所以大家很自然的就拿草莓酱的分级套到其他图的难度上了

    术语 别名 / 英文 说明
    beg beginner, 春一, 酱一 难度
    int intermediate, 春二, 酱二 难度
    adv advanced, 春三, 酱三 难度
    exp expert, 春四, 酱四, 姜丝 难度
    gm grandmaster, 春五, 酱五, 姜武 难度, gm+ 就是 gm 难度往上

    技巧相关

    术语 别名 / 英文 说明
    狼跳 狼, coyote jump 利用狼时间晚按跳
    hyper 大跳, 蹲姿大跳 蹲姿横冲被跳打断的技巧 (8C 教程)
    super 站姿横冲被跳打断的技巧
    超冲 super dash 是另一种玩法, 不要和 super 搞混
    凌波 凌波微步, wavedash 特殊 setup 的 hyper (9A / 第九章教程)
    兔子跳 bunnyhop 短 hyper/wave + 跳跃以获得近似 hyper/waver 的水平速度 + super 的垂直速度
    果冻 hyper dream hyper, 果嗨 利用出果冻冻结帧和狼跳帧做出的 hyper
    蹭墙 蹭, wallbounce 据说是蔚蓝最难技巧 (7B 教程)
    wb wallboost, 偷体力抓跳 不按方向抓跳后按离墙方向获得 27.5 体力
    Ultra u, 奥抓, 奥欻 经常伴随着斜下冲的加速技巧
    dd demodash, demo, 蹲冲 国人玩家 DemoJameson 发现的特性, 后来被官方认可并加入绑键设置
    cp ceiling pop 墙下抓跳
    cb cornerboost 利用阻挡还原和抓跳的组合技
    cg cornerglide 利用阻挡还原
    px pixel, 像素 像素
    1f, 2f, 3f, ... 帧, frame 帧数
    fp frame perfect, 帧完美 只有特定帧才能完成操作
    0f 无解 没有任何一帧能完成操作
    中性跳 neutral, neutral jump, 牛抽奖 不按方向的踢墙
    咖啡跳 cornerkick 本质上还是踢墙
    踢刺边 / 刺角 踩刺 (这个是错误的说法) 本质上还是踢墙
    预输入 buffer 提前按
    暂停预输入 pause buffer 可以一帧一帧玩
    瞬弹 Spring Cancel 碰到弹簧后预输入冲刺
    b4 freezeframe ungrab, 冻结帧不抓 弹球炼狱第 4 个草莓用到的技巧
