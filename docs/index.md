# Celeste Wiki

## 关于 Wiki

本 Wiki 旨在对蔚蓝做个资源和教程上的整合, 整体偏向制图, 力求你的大部分疑问都能在这获得解答(偏冷门/进阶的可以问群友), 减少重复性问题, 解放大佬双手, 虽然现在还是相对简陋, 但已初具雏形
